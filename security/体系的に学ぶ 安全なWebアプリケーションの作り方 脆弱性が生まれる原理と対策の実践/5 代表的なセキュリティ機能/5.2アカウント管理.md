# 5.2.1 ユーザー登録

ユーザー登録における機能的な注意点について取り上げる

## メールアドレスの受信確認

- メールアドレスを登録・変更する際には、登録されたメールアドレスに送信されるメールを利用者自身が受信できることを確認するべき
    - パスワード変更などのメールが誤って別人に届くと、セキュリティの問題につながるため
    - 方法
        - A. メールにトークン付きURLを添付して、そのURLから処理を継続する
            - ユーザーの操作性は良い
            - 利用者にメールのURLを閲覧させることは好ましくない
                - → この観点で本書では非推奨
            - 実装はやや面倒
        - B. メールアドレスを入力した後、トークン(確認番号)入力画面に遷移する。トークンは、指定したメールアドレスに送信される
            - 利用者にメールのURLを閲覧させることを避けられる
            - 確認番号を入力する操作が利用者にはやや面倒
            - 実装は容易

## ユーザーIDの重複防止

- Ex.
    - パスワードを違えば同じIDで登録できるサイト
    - ユーザーIDに一意制約をつけられないサイト
        - ユーザーIDの列にUNIQUE制約をつけられない
            - ユーザーの削除を論理削除にしているため、制約はつけられないとのこと
- リスク
    - 同一ユーザーIDで別のアカウントが作成できると、誤って別ユーザーとしてログインできる可能性が出てしまう
- 対策
    - 一意制約をつけることが望ましい
    - つけられない場合は、アプリケーション側で排他制御など細心の注意を払って、同じユーザーIDで登録できないようにする

## ユーザーの自動登録への対処

- 自動操作によって大量に新規ユーザーを作成される場合がある
- 自動登録が想定される、あるいはすでに被害が出ている場合はCAPTCHA(キャプチャ)という仕組みで対策する方法がある

### CAPTCHAによる自動対策

- Webサイトを操作しているユーザーが確かに人間であること
- コンピューターの自動応答でないことを確かめるために、わざと文字を歪めさせた画像を表示させ、利用者に文字列を入力してもらう方法
- Google社のreCAPTCHAが広く使われている

# 5.2.2 パスワード変更

パスワード変更におけるセキュリティ上の注意点について

- 現在のパスワードを確認すること
    - 現在のパスワードを入力してもらい照合する(再認証)
    - セッションハイジャックされた状態で第三者がパスワードを変更することを防止できる
- パスワード変更時のメール通知
    - 第三者が不正にパスワードを変更した場合でも、早期に利用者が気づくことができ、必要な対応を取ることができる
- パスワード変更機能に生じやすい脆弱性
    - SQLインジェクション脆弱性
        - 再認証を回避してパスワード変更や別ユーザーのパスワード変更など
    - CSRF脆弱性

# 5.2.3 メールアドレスの変更

- メールアドレスの不正変更に悪用される典型的な手口
    - セッションハイジャック
    - CSRF攻撃
    - SQLインジェクション攻撃
- 対策
    - 新規メールアドレスに対する受信確認
    - 再認証
    - メール通知
        - 旧メールアドレスにも通知する。第三者に変更された場合に気付けるようにするため

# 5.2.4.  パスワードリセット

## 管理者向けパスワードリセット機能

以下の順序で運用を行うのが良い

- 利用者の本人確認
    - あらかじめ登録された個人情報を電話で告げてもらうなど、サイトの性質によって適切な運用手順を決めておく
- 管理者がパスワードをリセットし、利用者に仮パスワードを伝える
    - メール送信等が望ましい
        - 悪用の心配がない
- 利用者は仮パスワードでログインし、直ちにパスワードを変更する

## 利用者向けパスワードリセット機能

- 管理者向けの機能同様、本人確認 → パスワードリセットというフロー
    - 本人確認
        - 登録済みメールアドレスのメールを受け取れることで本人であることを確認
        - 加えて2段階認証で、スマホアプリで生成される数字で本人確認を強化
    - パスワードの通知方法は以下2種類が推奨
        - 仮パスワードを発行してメールで通知する
            - 第三者が不正に変更しようとした時も、メールで気付ける
        - パスワード変更画面に直接遷移する
