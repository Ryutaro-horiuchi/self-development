# 5.3.2 認可不備の典型例

## 典型例

- 情報リソースのURLを知っていると認証なしで情報が閲覧できる
    - 当該ページで認証状態の確認を怠っているのが原因
- 情報リソースのIDを変更すると権限外の情報が参照できる
- メニューの表示・非表示のみで制御している
    - URLから管理画面のURLを類推して、アドレスバーを書き換えると管理者メニューが表示されてしまうなど
- hiddenパラメーターやクッキーに権限情報を保持している
    - 例えばクッキーに`userkind=admin`と指定すれば管理者機能が使えるようになってしまうサイトなど

## 対策

権限情報をセッション変数に保持することで書き換えできなくすること、処理や表示の直前に権限の確認をすることが必要
